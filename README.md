Tarea de hacer una calculadora con sping boot usando operaciones como @PathVariable, 
RequestParam, RequestBody.

Use el PathVariable para la resta, RequestParam para la suma y RequestBody para la multi.
Tambien descargue el REST client que se habia visto en clase pero use la extension de VSCode
para poder ejecutar y verificar desde el mismo IDE, encontraras los archivos .http en la carpeta de 
controller para la ejecucion rapida de cada operacion.
